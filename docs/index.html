⚙️ 고급 설정

🛰️ OpenSky Network 항공 신호 추적

우체국 API 응답에서 우편 EDI 라우팅 코드(예: UAIEVCKRSELBAUX60062)가 감지되면, 코드에 포함된 공항 정보를 파싱해 실제 화물 항공기를 OpenSky Network에서 조회하고 추적 이력에 병합합니다.

⚠️ 우편 EDI 라우팅 코드는 SITA 주소가 아닙니다. 직항 경로가 아닌 경우도 많으며(예: 키이브→인천 실제 경로: 바르샤바/리가/프랑크푸르트 경유), OpenSky는 보조 참고 데이터로만 활용됩니다. 실제 배송 추적은 UPU S10 송장번호가 기준입니다.

⚠️ 비밀번호가 브라우저 로컬스토리지에 암호화 없이 저장됩니다. 반드시 OpenSky 전용 계정을 사용하고 주 비밀번호를 입력하지 마세요.

해운 경로 탐색 베타

해운 경로 기능은 현재 실험적 베타 단계입니다. 해운 레인 데이터를 기반으로 해상 운송 경로를 분석하지만, 항공 데이터에 비해 정확도가 낮을 수 있습니다.

  • 해운 데이터는 글로벌 주요 항로만 포함하며 정기선 시간표는 반영되지 않습니다.
  • 항구 코드(IATA 형식 아님)가 표시될 수 있으며, 정확한 항구명 매핑이 제한적입니다.
  • 이 기능을 사용하려면 generate_all.sh --with-maritime으로 해운 데이터를 포함해 데이터베이스를 재생성해야 합니다.
🚢 해운 경로 기능이 곧 추가될 예정입니다.
현재 데이터베이스에는 항공 노선만 포함되어 있습니다.
generate_all.sh --with-maritime을 실행해 해운 데이터를 활성화하세요.
