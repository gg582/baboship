해운 경로 탐색 베타

해운 경로 기능은 현재 실험적 베타 단계입니다. 해운 레인 데이터를 기반으로 해상 운송 경로를 분석하지만, 항공 데이터에 비해 정확도가 낮을 수 있습니다.

  • 해운 데이터는 글로벌 주요 항로만 포함하며 정기선 시간표는 반영되지 않습니다.
  • 항구 코드(IATA 형식 아님)가 표시될 수 있으며, 정확한 항구명 매핑이 제한적입니다.
  • 이 기능을 사용하려면 generate_all.sh --with-maritime으로 해운 데이터를 포함해 데이터베이스를 재생성해야 합니다.
🚢 해운 경로 기능이 곧 추가될 예정입니다.
현재 데이터베이스에는 항공 노선만 포함되어 있습니다.
generate_all.sh --with-maritime을 실행해 해운 데이터를 활성화하세요.
